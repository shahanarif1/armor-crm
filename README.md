# ARMOR CRM

A polished, responsive Next.js starter for ARMOR CRM.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```

## Deploy on Netlify

Import this GitHub repository into Netlify. Netlify's Next.js runtime/plugin will detect the framework; use `npm run build` as the build command. No environment variables are required for this starter.
