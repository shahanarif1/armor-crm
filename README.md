# ARMOR CRM

A polished, responsive Next.js starter for ARMOR CRM.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
```

## Deploy on Netlify

Connect this repository to Netlify with the repository root as the base directory and `npm run build` as the build command. The repository includes `netlify.toml` for Netlify's Next.js runtime configuration; allow Netlify to install dependencies and run the build (do not upload the `.next` directory as a static site). The runtime plugin handles the Next.js App Router and routing. No environment variables are required for this starter.
